# Atesen MCP servers

Two zero-dependency stdio MCP servers that expose public-data Apify Actors as tools (you bring your own Apify token; Apify bills your account per run, capped per call by `ATESEN_MAX_CHARGE_USD`, default 0.25 USD).

| Server | npm | Registry name |
|---|---|---|
| `servers/company-data` | `atesen-company-data-mcp` | `io.github.pabsamuel/atesen-company-data-mcp` |
| `servers/web-data` | `atesen-web-data-mcp` | `io.github.pabsamuel/atesen-web-data-mcp` |
